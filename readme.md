# Simple Web Project

A minimal starter project with HTML, CSS, and JavaScript — perfect for learning or as a base for bigger things.

---

## 📁 Project Structure
project/
├── index.html # Main HTML page
├── style.css # Stylesheet
├── script.js # JavaScript logic
└── README.md # This file


---

## 🚀 Getting Started

1. **Download or clone** the project files into a folder.
2. Make sure all files (`index.html`, `style.css`, `script.js`) are in the **same directory**.
3. **Open `index.html`** in any modern web browser — that's it!

No build tools, no dependencies, no installation needed.

---

## 🧩 What's Included

### `index.html`
- Basic page structure (`<!DOCTYPE html>`, `<head>`, `<body>`)
- Links to `style.css` and `script.js`
- A sample layout with a heading, paragraph, and buttons

### `style.css`
- CSS reset for consistent rendering
- Base typography and colors
- Styled container card with shadow
- Button hover effects
- Responsive images

### `script.js`
- Runs after the page loads (`DOMContentLoaded`)
- Button click handlers
- Simple form validation
- Example functions, arrays, and arrow functions

---

## 🛠️ How to Customize

| Want to...             | Edit this file |
|------------------------|----------------|
| Change content/text    | `index.html`   |
| Change colors/layout   | `style.css`    |
| Add interactivity      | `script.js`    |

## 💡 Tips

- Open the **browser console** (`F12` → Console) to see the `console.log` messages.
- Try commenting out sections to see what each part does.
- Add new elements to the HTML, style them in CSS, and make them interactive with JS.
